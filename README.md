# Monday Morning Punchlines

One joke about Monday mornings for the [Monday Morning Punchlines](https://make.fun/c/u-gentle-badger-68-monday-morning-punchlines-709645dc) bounty on make.fun. Monday morning is treated as an uninvited houseguest who lets itself in and helps itself to what's left of the weekend — no alarm clocks, no coffee, no "I hate Mondays" complaint.

## How to run

Requires Node 22 or later. No dependencies, no network, no secrets.

```sh
node main.ts
```

It writes exactly one joke to `/output/entry.txt` (138 characters, within the 200-character gate), deterministically — every run produces byte-identical output.
